1. システムの概要

Wakaru は、学生が「授業についていけない」と感じたときにリアルタイムで先生に知らせるシステムです。

ツール利用者動作方法
管理ツール（本書）先生先生PCで起動。サーバーを兼ねる
学生ツール学生Teamsから入手してダブルクリック起動
⚠ 管理ツールと学生ツールは同じネットワーク（同一セグメント）内で使用してください。
学生ツールは先生PCを自動で検索するため、IP アドレスの入力は不要です。

2. 初回起動・初期設定

起動方法

  1. Wakaru_Teacher.exe をダブルクリックします。
  2. 初回のみ「ファイアウォール設定」ダイアログが表示されます。
    「はい」を選ぶと Windows の UAC 確認が表示されます。「はい」をクリックしてください。
  3. 管理ツールのメイン画面が開きます。
ファイアウォール設定は初回のみです。2回目以降は自動的にスキップされます。

先生の登録（必須）

  1. 「⚙ 設定」ボタンをクリックします。
  2. 「先生管理」タブで先生の名前を入力し、「追加」をクリックします。
  3. 授業を担当する先生を全員登録してください。学生がこのリストから選択します。
  4. 「保存して閉じる」をクリックします。

最前面表示

「最前面に表示」チェックをオンにすると、他のウィンドウの手前に常に表示されます。PowerPoint スライドショー中でも確認できます。

4. 設定

先生管理タブ

  • 追加：テキストボックスに名前を入力して「追加」ボタンをクリック
  • 削除：リストから名前を選択して「削除」ボタンをクリック
  • 登録された先生リストは学生ツールに自動配信されます

閾値設定タブ

設定項目説明例
割合 (%) 接続学生に対する割合で判定 30 → 30人中9人以上で警告
人数 絶対人数で判定 5 → 5人以上で警告

5. 授業ログの確認

「📋 ログ」ボタンをクリックするとログビューアが開きます。

ログビューアの操作

  • 日付を入力して「読み込み」→ その日のログを一覧表示
  • 画面下部に時限ごとの件数集計が表示されます
  • 「フォルダを開く」→ ログファイルが保存されているフォルダを開く

ログファイルの場所と形式

管理ツール（.exe）と同じフォルダ内の logs フォルダに日付ごとの CSV ファイルが保存されます。

例：logs\2026-11-18.csv
Excel でそのまま開けます（文字コード: UTF-8 BOM付き）。

6. トラブルシューティング

学生が接続できない

  • 管理ツールが起動しているか確認してください
  • 先生PCと学生PCが同じネットワーク（同一セグメント）に接続されているか確認してください
  • ファイアウォール設定が完了しているか確認してください（初回起動時に「はい」を選んだか）

先生リストが学生ツールに表示されない

  • 設定 → 先生管理 で先生が登録されているか確認してください
  • 学生ツールを再起動してください（再接続で最新リストを取得します）

ファイアウォール設定ダイアログが再表示される

  • 前回の設定が完了していない可能性があります
  • 「はい」を選択し、UAC の確認で「はい」をクリックしてください
  • 手動で設定する場合はコマンドプロンプト（管理者）で下記を実行してください：
netsh advfirewall firewall add rule name="Wakaru-WebSocket" dir=in action=allow protocol=TCP localport=8765
netsh advfirewall firewall add rule name="Wakaru-UDP-Discovery" dir=in action=allow protocol=UDP localport=9999

ログファイルが保存されない

  • 学生が情報（学籍番号・氏名）を入力して「保存して接続」をしているか確認してください
  • 「ついていけない」ボタンを押した後、解除されるまで（自動1分または切断）の間でログが確定します
